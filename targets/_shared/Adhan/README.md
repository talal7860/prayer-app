# adhan-swift (vendored)

Swift sources of https://github.com/batoulapps/adhan-swift at commit 55a1350 (MIT, see LICENSE),
flattened into one folder. The phone uses the JavaScript port of the same library (`adhan`
on npm), so the watch and the phone calculate the same times.

`@bacons/apple-targets` has no Swift Package support, hence the copy. To update: replace these
files with `Sources/**/*.swift` from a newer commit.
